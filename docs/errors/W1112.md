# W1112

**`import` or `export` statement dropped; move shared content into `snippets/`**

| | |
|---|---|
| Severity | Warning |
| Area | Importers |
| Raised by | `liyasa-import` |

An MDX `import` or `export` statement had no Liyasa equivalent and was removed
from the converted page. It is always removed, because an `import` left in
Markdown renders to the reader as a paragraph of JavaScript.

What reaches this is genuine logic, typically something like
`import { chart } from '../lib/chart.js'`.

## Fix it

Move shared content into `snippets/`, or a computed value into front matter or a
[fact](/guides/fact-modelling).

Not raised for the cases the importer converts: an import of a `.md` or `.mdx`
partial becomes `{% snippet "name" %}` and the partial moves into `snippets/`;
an `export const NAME = "literal"` becomes front matter; a Docusaurus `@theme/`
or `@docusaurus/` import is boilerplate and goes silently; and an import whose
bindings are all component names is reported through the component instead, as
[`W1110`](/errors/W1110).
