# E0012

**Scaffold target directory already has files in it**

| | |
|---|---|
| Severity | Error |
| Area | CLI and I/O |
| Raised by | `liyasa-cli` |

`liyasa new` was pointed at a directory that already has files in it, and the
message names the first one it found.

Scaffolding into an occupied directory either overwrites work or interleaves a
starter with an existing project. Neither is recoverable by reading the output,
so it refuses instead.

## Fix it

Pick a directory that is empty or does not exist yet:

```sh
liyasa new acme-docs
```

To add Liyasa to a repository that already holds something else, create the
project beside it and move the files in, or write `liyasa.json` by hand and set
`"root"` to the subdirectory your documentation lives in. See
[project layout](/getting-started/project-layout).
