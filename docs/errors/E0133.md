# E0133

**Navigation binds a subtree to a version, locale, product, or spec that is not declared**

| | |
|---|---|
| Severity | Error |
| Area | Configuration |
| Raised by | `liyasa-config` |

A navigation node binds a subtree to a version, locale, product, or spec that
`liyasa.json` does not declare.

## Fix it

Declare the dimension value before binding to it:

```json
{
  "locales": [{ "code": "en", "default": true }, { "code": "de" }],
  "navigation": {
    "pages": [{ "language": "de", "pages": ["de/index"] }]
  }
}
```

The same holds for `{ "version": … }` against `versions`, `{ "product": … }`
against `dimensions`, and `{ "openapi": … }` against the `openapi` sources.
