# W0306

**Heading level skipped**

| | |
|---|---|
| Severity | Warning |
| Area | Markdown, directives |
| Raised by | `liyasa-markdown` |

A heading skips a level: an `h4` directly under an `h2`.

The heading outline is what screen-reader users navigate by and what agents
chunk on, so a gap in it is a real loss of structure rather than a formatting
nit.

## Fix it

Use the level the structure calls for. If the motivation was a smaller heading,
that is a styling decision: change the theme, not the level.
