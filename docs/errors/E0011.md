# E0011

**Command needs a built site and the output directory was not found**

| | |
|---|---|
| Severity | Error |
| Area | CLI and I/O |
| Raised by | `liyasa-cli` |

The command needs a site that has already been built, and the output directory
is not there.

`liyasa test`, `liyasa export`, `liyasa search`, and `liyasa deploy` read what a
build wrote. They do not build for you: a command that silently built would hide
which step was slow and which one failed.

## Fix it

```sh
liyasa build
liyasa test --agents
```

Or point at a directory that exists:

```sh
liyasa export --output dist-preview
```

If you did build and the directory is still missing, check `build.output` — the
build writes where the configuration says, and `--output` overrides it for one
command only.
