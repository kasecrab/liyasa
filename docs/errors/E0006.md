# E0006

**Feature not available in this build**

| | |
|---|---|
| Severity | Error |
| Area | CLI and I/O |
| Raised by | `liyasa-cli` |

The feature exists in Liyasa, but not in the binary you are running.

Liyasa ships as one binary with the build and verification engines in it. Some
capabilities live behind a feature or in a separate crate, and a build without
one says so rather than failing in a way that looks like your project is wrong.

## Fix it

The message names the feature and the help line names the alternative. The two
you are most likely to meet:

- **`liyasa serve`** needs the server crate. `liyasa dev` serves a built site
  locally for everything short of running a production deployment.
- **`liyasa export --zip`** is not in every build. Export the directory and
  archive it with your own tool.

This is not the same as [`E0003`](/errors/E0003), which is a feature that is
present but needs the companion runtime installed.
