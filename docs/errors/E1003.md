# E1003

**Search index is truncated or corrupt**

| | |
|---|---|
| Severity | Error |
| Area | Search and the browser index |
| Raised by | `liyasa-search` |

This diagnostic comes from `liyasa-search`. The message carries the file, the line, and the value that caused it; run the command again with `--json` to get it as structured output.

## Getting help

[Build errors](/help/build-errors) covers the codes in this range, what usually causes them, and what to try first.

Every code is listed in [the error reference](/errors).
