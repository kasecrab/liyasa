# E1003

**Search index is truncated or corrupt**

| | |
|---|---|
| Severity | Error |
| Area | Search and the browser index |
| Raised by | `liyasa-search` |

:::info{title="This page is not written yet"}
`E1003` is registered and raised by `liyasa-search`, and everything above is generated from the registry. What causes it and how to fix it has not been written yet.

The message itself carries the file, the line, and the value that caused it; `--json` gives you the same as structured output.
:::
