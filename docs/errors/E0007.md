# E0007

**Release signature verification failed**

| | |
|---|---|
| Severity | Error |
| Area | CLI and I/O |
| Raised by | `liyasa-cli` |

`liyasa update` downloaded a release, and the signature over its digest did not
verify against the release key.

## What to do

Do not retry until it passes, and do not work around it. A signature that does
not verify means the bytes are not the bytes that were published: a corrupted
transfer on a good day, and a substituted artifact on a bad one.

Install from the releases page instead, and verify the checksum yourself before
running anything:

```sh
sha256sum liyasa-x86_64-unknown-linux-musl.tar.gz
```

If the published checksum matches and `liyasa update` still refuses, the release
key this binary carries may be older than the key that signed the release, which
is worth reporting.

[`E0008`](/errors/E0008) is the neighbouring failure: the digest itself did not
match.
