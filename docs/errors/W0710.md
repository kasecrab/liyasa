# W0710

**Page exceeds the per-page variant cap and is marked dynamic**

| | |
|---|---|
| Severity | Warning |
| Area | Build, cache, assets, determinism |
| Raised by | `liyasa-build` |

:::info{title="This page is not written yet"}
`W0710` is registered and raised by `liyasa-build`, and everything above is generated from the registry. What causes it and how to fix it has not been written yet.

The message itself carries the file, the line, and the value that caused it; `--json` gives you the same as structured output.
