# E1200

**Editor session request is not valid (nonce or site metadata)**

| | |
|---|---|
| Severity | Error |
| Area | Editor and WebAssembly |
| Raised by | `liyasa-wasm` |

The editor asked the WebAssembly module to open a session and one of the values
it needs was missing or malformed.

`nonce` is 32 hexadecimal characters and the host generates a fresh one per
session. It is not optional and it does not default: the nonce is what makes a
directive marker unforgeable, so a preview that ran with a predictable one would
parse a marker an author typed into the page as a component nobody declared.
`canonical_origin` and `llms_txt` are absolute URLs, because the Markdown
serialization an agent fetches resolves links against them.

## Fix it

Generate the nonce where the draft session is created, not in the page:

```js
const nonce = [...crypto.getRandomValues(new Uint8Array(16))]
  .map((b) => b.toString(16).padStart(2, "0"))
  .join("");
```

Send the site's real origin with it; `liyasa.json`'s `site.canonicalOrigin` and
the built `llms.txt` URL are what the preview endpoint uses for the same page.

Related: [W1201](/errors/W1201) when the page is too large to preview in the
browser at all.
