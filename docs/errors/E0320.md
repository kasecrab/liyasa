# E0320

**Untrusted (below `operator`) value contains a line break and was rejected from interpolation**

| | |
|---|---|
| Severity | Error |
| Area | Markdown, directives |
| Raised by | `liyasa-markdown` |

This diagnostic comes from `liyasa-markdown`. The message carries the file, the line, and the value that caused it; run the command again with `--json` to get it as structured output.
