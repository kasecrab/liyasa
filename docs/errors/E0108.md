# E0108

**No default version or locale declared**

| | |
|---|---|
| Severity | Error |
| Area | Configuration |
| Raised by | `liyasa-config` |

This diagnostic comes from `liyasa-config`. The message carries the file, the line, and the value that caused it; run the command again with `--json` to get it as structured output.
