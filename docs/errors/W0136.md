# W0136

**`seo.canonicalOrigin` already carries `build.basePath`, so every absolute URL doubles it**

| | |
|---|---|
| Severity | Warning |
| Area | Configuration |
| Raised by | `liyasa-config` |

`seo.canonicalOrigin` ends in the same path segment `build.basePath` adds, so
every absolute URL the build writes carries it twice —
`https://example.com/docs/docs/guide/install`.

The two keys describe different things. `seo.canonicalOrigin` is the origin in
the SEO sense: scheme, host, and port. `build.basePath` is the prefix the site
is served under, and it is the only place that prefix belongs: the build adds it
to in-page links, to assets, to the Markdown twins, and to `llms.txt`.

## Fix it

Take the prefix out of the origin and leave it in `build.basePath`:

```json
{
  "seo": { "canonicalOrigin": "https://example.com" },
  "build": { "basePath": "/docs" }
}
```

A site whose origin genuinely carries a path and that sets no `build.basePath`
is not this warning and needs no change.

See [W0131](/docs/errors/W0131) for a missing origin.
