# E0805

**Rollback target not retained**

| | |
|---|---|
| Severity | Error |
| Area | Server, auth, deployments, network |
| Raised by | `liyasa-server` |

The build you asked to roll back to is no longer retained, so there is nothing
to point the environment at.

Bundles are kept per the retention policy — the last fifty production builds by
default — and a build past that window has had its bundle removed. A build that
never succeeded is also not a rollback target, because its bundle was never
written.

## Fix it

Ask which builds are still retained for the environment before choosing one:

```
GET /_liyasa/api/v1/deployments/production/retained?project=<id>
```

If you need to go back further than the policy keeps, raise the retention count
before you need it rather than after — a bundle that has been removed cannot be
recovered without rebuilding the commit.

A build an environment currently points at is never removed, however old it is,
so the version you are serving is always a valid rollback target.

See [E0804](/docs/errors/E0804) for a rollback that failed for another reason.
