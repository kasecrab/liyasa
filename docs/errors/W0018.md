# W0018

**External links were not checked; this build has no network client**

| | |
|---|---|
| Severity | Warning |
| Area | CLI and I/O |
| Raised by | `liyasa-cli` |

External links were not requested, so they were not checked. Internal links,
anchors, and assets were.

This warning exists so that a link run which covered only what is in the
repository never reads as a clean bill of health for every link on the site.

## Fix it

Nothing is broken. If you want external links checked, run the verification that
covers them, on a machine with a network:

```sh
liyasa broken-links
```

External links are checked on a schedule rather than on every build, because a
network round trip per link makes builds slow and flaky for reasons outside your
repository. A failing one is [`W0404`](/errors/W0404). See
[linking](/guides/linking).
