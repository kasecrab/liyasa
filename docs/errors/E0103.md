# E0103

**Unknown config key**

| | |
|---|---|
| Severity | Error |
| Area | Configuration |
| Raised by | `liyasa-config` |

This diagnostic comes from `liyasa-config`. The message carries the file, the line, and the value that caused it; run the command again with `--json` to get it as structured output.

## Getting help

[Build errors](/help/build-errors) covers the codes in this range, what usually causes them, and what to try first.

Every code is listed in [the error reference](/errors).
