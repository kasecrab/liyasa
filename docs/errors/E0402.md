# E0402

**Broken heading anchor**

| | |
|---|---|
| Severity | Error |
| Area | Navigation and links |
| Raised by | `liyasa-build` |

A link points at a heading anchor that does not exist on the target page.

Anchors are derived from heading text, so editing a heading breaks every link to
it. That is usually what happened.

## Fix it

Give the heading a stable identifier, and the link survives the next rewording:

```markdown
## Rate limits {#limits}
```

Then link to `/guides/limits#limits`.
