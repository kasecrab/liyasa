# E0013

**Starter template not found**

| | |
|---|---|
| Severity | Error |
| Area | CLI and I/O |
| Raised by | `liyasa-cli` |

`--template` named a starter that does not exist.

## Fix it

This release ships one starter, which is what you get without the flag:

```sh
liyasa new acme-docs
```

`--template <name|url>` is specified to take a name from a registry or a git
URL. Neither the registry nor the clone exists yet, so every name is unknown
today, and the error says that rather than fetching something arbitrary.

`liyasa theme` raises the same code for a partial that is not one the theme
defines; `liyasa theme eject` lists the names that are.
