# E0854

**A project's region is chosen when it is created and cannot be changed**

| | |
|---|---|
| Severity | Error |
| Area | Server, auth, deployments, network |
| Raised by | `liyasa-server` |

A region is a promise about where analytics and assistant data are stored, and
it is made when the project is created. Changing it afterwards would leave
every row already written in the old region while the setting claimed
otherwise, so there is no operation that does it.

## Fix it

Create a project in the region you want and move the content into it:

```
liyasa org project create docs-eu --region eu
liyasa org project export docs --out docs.tar.zst
liyasa org project import docs-eu --from docs.tar.zst
```

Analytics history does not come across: it was collected under a residency
promise about the old region. The new project starts with an empty series, and
the old project's history stays readable until it is deleted.

Related: [E0855](E0855.md) when a request tries to write a project's data
somewhere other than its own region.
