A container directive was opened and never closed.

## Fix it

The usual cause is nesting. A container inside another container needs **more
colons on the outer one**:

```markdown
::::cards{cols=2}

:::card{title="Inner"}
The outer fence has four colons, the inner three.
:::

::::
```

With three colons on both, the first `:::` closes the outer container and the
rest of the page drifts. [`E0311`](/errors/E0311) is the same mistake seen from
the other end.
