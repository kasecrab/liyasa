A fact source refreshed, and its data no longer matches the schema declared for
it.

The shape changed underneath you. That is a much better failure than a page
rendering an empty value.

## Fix it

```toml
[[source]]
id = "pricing"
kind = "file"
path = "facts/pricing.json"
schema = "facts/pricing.schema.json"
```

Update the schema if the change is intended, and treat it as a finding about the
product if it is not. A `url` or `command` source without a schema will not
catch this, which is why both should have one.
