A class of verification check did not run in this build. The message names the
class and why.

| Class | What it needs |
|---|---|
| `code` | The verification orchestrator and a container sandbox |
| `facts` | The verification orchestrator |
| `screenshots` | The companion runtime |
| `prose` | The page syntax tree the orchestrator supplies |

## What to do

Read it before trusting a green verification run. "No findings" means something
quite different when a whole class was skipped, and this warning is the only
thing that distinguishes the two.

To make a class run, give it what it needs: a container runtime for `code`
([`E0004`](/errors/E0004)), the companion for `screenshots`
([`E0003`](/errors/E0003)). See [sandbox setup](/help/sandbox) and
[verification](/guides/verification).

In CI, treat this as a failure rather than a warning if the class is one you
depend on. A check you believe is running and is not is worse than one you know
is absent.
