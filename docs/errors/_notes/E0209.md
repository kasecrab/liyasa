A page refers to a fact that is not declared.

## Fix it

Facts are declared in `facts/sources.toml` and referenced by their dotted
identifier:

```toml
[[source]]
id = "limits"
kind = "file"
path = "facts/limits.json"
```

```markdown
The API allows :fact{id="limits.api.requests_per_minute"} requests per minute.
```

The identifier is the source `id` followed by the path into its data, so a
typo in either half produces this. See
[fact modelling](/guides/fact-modelling).
