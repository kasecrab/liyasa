A `{{ name }}` in a page refers to something the template context does not
provide.

The context is, in order of precedence: site `variables`, `snippets/vars.json`,
facts from `facts/`, dimension values (`version`, `locale`, `product`,
`region`), the page's own front matter as `page.*`, `site.*`, `nav.*`, `env.*`
for variables allow-listed in `build.env`, and `reader.*` only on pages that
declare `personalized: true`.

## Fix it

`content.templating.undefined` decides what happens: `strict` makes this an
error, `lenient` renders a visible marker in the dev server. Keep it strict in
CI, because a silently empty value reads as a deliberate blank.

If the name is a fact, check it is declared in `facts/sources.toml`; a missing
one is [`E0209`](/errors/E0209) instead.
