A component was written in one of the three directive forms and the registry
declares it as another.

## Fix it

Match the form to the kind the component declares. `::card` is the leaf form, so
a container like `card` has to open and close:

```markdown
:::card{title="Inner"}
Content between the fences.
:::
```

The same applies the other way. An inline component in the container form —
`:::kbd` with a body — is this error too; write it as `:kbd[X]` inside the
sentence it belongs to.

An empty body is still a container: `:::note` followed by `:::` is fine, and is
not the same thing as `::note`. What the parser reads is the **form written**,
not the emptiness of the body.

[`E0313`](/errors/E0313) is a name the registry does not have at all.
[`E0310`](/errors/E0310) is the container form left unclosed.
