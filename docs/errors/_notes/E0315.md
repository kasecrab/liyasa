A prop was given a value of the wrong type.

## Fix it

Props are typed, and the syntax distinguishes the types:

| Type | Written as |
|---|---|
| String | `title="Install"` |
| Number | `cols=2` |
| Boolean | `open=true` |
| List | `only=[us,eu]` |

Quoting a number (`cols="2"`) is the most common form of this error. Each
component's prop types are in [the component gallery](/reference/gallery),
generated from the same schema the build validates against.
