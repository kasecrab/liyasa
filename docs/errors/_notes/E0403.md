A page refers to an image, a download, or another asset that the build did not
produce.

## Fix it

Assets live under `assets/` and are copied to `dist/` with stable URLs. An
absolute path is resolved from the project root, a relative one from the page.

```markdown
::image{src="/assets/dashboard.png" alt="The deployment list"}
```

Check the case of the file name. It works on macOS and Windows, whose file
systems usually ignore case, and fails on the Linux host that serves the site.
