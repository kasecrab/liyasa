A component was used without one of its required props.

## Fix it

Required props are marked in [the component gallery](/reference/gallery), which
is generated from the same schema the build validates against. The ones people
miss most often:

| Component | Required |
|---|---|
| `image` | `src`, `alt` |
| `iframe` | `src`, `title` |
| `fact` | `id` |
| `param`, `response-field` | `name` |
| `openapi-schema` | `spec`, `schema` |

`alt` and `title` are required rather than optional because a missing one is
unusable for a reader using a screen reader, not merely untidy.
