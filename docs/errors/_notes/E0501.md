An OpenAPI document did not validate. The message carries a JSON pointer to the
place that failed.

## Fix it

The pointer is the fastest way in: `/paths/~1v1~1deployments/get/responses/200`
reads as `paths` → `/v1/deployments` → `get` → `responses` → `200`. In a JSON
pointer, `~1` is a literal `/` and `~0` is a literal `~`.

Validate the document against its own version's schema before pointing Liyasa at
it. Most editors will do this from the `openapi` field alone.

[`E0504`](/errors/E0504) is the neighbouring case: a version Liyasa does not
support. Swagger 2.0 is converted automatically, which is
[`W0509`](/errors/W0509).
