`verify-chain` runs a `steps` block's code in one sandbox, in order, so step
two can use what step one left behind. That needs one process, and these steps
do not share a language — or one of them is not a code block at all.

## Fix it

Give every step the same language, or drop `verify-chain` and let each block be
its own check:

````markdown
:::steps verify-chain
```bash verify
export TOKEN=abc
```

```bash verify expect="abc"
echo "$TOKEN"
```
:::
````

Blocks in a `code-group` or `tabs` are always verified independently; only
`steps` may chain.
