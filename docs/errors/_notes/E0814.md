A domain belongs to one project at a time, and the host being added is already
serving another one. Adding it a second time would make which project answers a
request a matter of which record was written last.

## Fix it

If the domain is yours and you are moving it between projects, claim it as a
contest and prove ownership with a TXT record:

```
_liyasa-challenge.docs.example.com.  TXT  "liyasa-site-verification=<token>"
```

The claim does not take effect when it is made. It takes effect when the record
resolves, and the project holding the domain is notified at that moment, so a
transfer is never silent.

If the domain is not yours, the organization holding it has to release it
first — there is no path through this error that does not involve them.

Related: [E0801](E0801.md) when the record is published and does not check out.
