A node in `navigation` names a page that the build did not find.

Almost always a page that was renamed or moved without updating the navigation
tree. The message names the path it looked for.

## Fix it

Navigation nodes take a **source path or a route**, not a file name:

```json
{ "group": "Guides", "pages": ["guides/install"] }
```

`guides/install`, not `guides/install.md`.

If the page really is gone, remove the node and add a
[redirect](/guides/linking) so the old URL still resolves.

:::warning{title="A silent version of this exists"}
A directory named `components`, `snippets`, `facts`, `theme`, or `assets`
anywhere in a path makes everything under it non-routable, and a
`{ "directory": … }` node pointed at one resolves to nothing rather than to
this error. If a whole section vanished without a diagnostic, check its
directory names.
:::
