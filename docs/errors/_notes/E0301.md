A fenced code block was opened and never closed.

## Fix it

The closing fence must be at least as long as the opening one. A block that
itself contains a fence therefore needs a longer outer fence:

`````markdown
````markdown
```sh
liyasa build
```
````
`````

Four backticks outside, three inside. With three on both, the first inner fence
closes the outer block and the rest of the page is parsed as code.
