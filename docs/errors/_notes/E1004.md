A search query is not well formed: an unbalanced quote, or a field filter the
index does not know.

## Fix it

Quote a phrase with a matching pair of double quotes, and use `field:value` only
for fields the index carries (`title`, `tab`, `version`, `locale`, `type`).

```sh
liyasa search '"rate limits" version:v2'
```

For a query that comes from a reader rather than from you, this is a message to
show, not a failure to log: it means what they typed cannot be parsed, and the
useful response is to search for it literally.
