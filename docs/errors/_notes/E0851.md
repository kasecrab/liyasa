Every member of an organization takes a seat, and so does every invitation that
has not been accepted or revoked yet — an invitation is a seat held open. The
plan has no seat left for the person being added.

## Fix it

Revoke an invitation nobody accepted, or remove a member who no longer needs
access:

```
liyasa org invites list
liyasa org invites revoke <id>
liyasa org members remove <email>
```

Free carries three seats. Pro bills per seat and has no limit, so upgrading
adds seats rather than buying a fixed block:

```
liyasa org plan --set pro
```

A reader signing in to a private site is not a member and takes no seat; only
someone with a dashboard role does.

Related: [E0856](E0856.md) for the project limit, which is counted separately.
