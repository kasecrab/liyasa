A per-directory review cadence names a directory this project has no pages in,
so that cadence never applies to anything. The pages you meant to review more
often keep the site-wide cadence, and nothing else says so.

An override key is a directory route, matched by prefix — `reference` covers
`reference/api` and everything under it. It is not a glob: `reference/*` is a
route no page can have, so it matches nothing.

## Fix it

Write the directory rather than a pattern, and check the spelling against the
directories the project actually has:

```json
{ "content": { "reviewCadence": {
    "default": "180d",
    "overrides": { "reference": "30d", "reference/api": "7d" } } } }
```

The longest matching prefix wins, so `reference/api` above tightens what
`reference` set. A key with leading or trailing slashes is the same directory.

If the directory is one you are about to add, the warning goes away when the
first page in it does.
