A prop was given that the component does not define. It is ignored.

## Fix it

Check the spelling against [the component gallery](/reference/gallery), which
lists every prop of every component, generated from the schema the build
validates against.

This is a warning rather than an error so that content written for another
documentation tool still builds while you migrate it. On a site you control,
`--strict` turns it into a failure, which is what you want once the migration is
done.
