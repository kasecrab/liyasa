A template used a filter or function that does not exist.

## Fix it

Check the spelling. Liyasa's own filters include `currency`, `number`, `date`,
and `slug`; its functions include `link()`, `pages()`, `asset()`, `openapi()`,
and `now()`.

A build-backed function called in a build that did not supply the data it needs
reports what was missing ([`E0216`](/errors/E0216)) rather than reporting the
name as unknown, so this really does mean the name is wrong.
