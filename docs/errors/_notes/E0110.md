The key is not in the configuration schema at all. Usually a typo, or a key
carried over from another documentation tool by an importer.

`schemas/liyasa.schema.json` is the single source of truth for configuration,
and [the configuration reference](/reference/config) is generated from it. If a
key is not documented there, it does not exist.

## Fix it

Check the spelling against the reference, and delete the key if it came from
another tool. [`E0102`](/errors/E0102) is the neighbouring case: the key exists
but the value has the wrong shape.
