The source page changed after its translation was written. The ledger at
`locales/.liyasa-translations.json` records which version of the source each
translation was made from, and this page's source no longer matches it, so the
translated text describes something the site no longer says.

## Fix it

Let the translate automation propose the update:

```sh
liyasa translate --locale de --stale
```

It reads the ledger, fetches the source as it was at the recorded revision, and
proposes a new translation alongside a diff of what changed in the source, so a
reviewer sees the edit rather than a whole rewritten page.

To update a page by hand instead, edit the translation and record what it was
translated from:

```json
{
  "de": {
    "/guides/install": { "source": "blake3:…", "revision": "a1b2c3d" }
  }
}
```

A translation the ledger has no entry for is not reported: a site translated by
hand before the ledger existed is unrecorded rather than stale, and the first
automation run records its provenance.
