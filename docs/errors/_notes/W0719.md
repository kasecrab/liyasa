A page started loading an image or a media file from a host that was not
previously in the content security policy, and the host was added.

Nothing is broken. This is a notice that the set of places your documentation
loads from has grown.

## Fix it

Read it as a review prompt. A new host is fine when someone embedded a video on
purpose and worth questioning when nobody remembers adding it.

To fix the set rather than let it grow, list the hosts you intend to allow and
let anything else fail:

```json
{ "network": { "allowHosts": { "embeds": ["player.vimeo.com"] } } }
```
