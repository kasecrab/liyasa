A command was given a git reference it could not resolve, or was run outside a
git repository. `liyasa verify --changed <ref>` is the one that asks for one:
it needs a commit to compare the working tree against.

## Fix it

Name a reference this repository has:

```sh
git rev-parse --verify origin/main   # does this resolve?
liyasa verify --changed origin/main
```

A shallow clone is the usual cause in CI — `actions/checkout` fetches one
commit by default, so `origin/main` is not there to compare against. Fetch more
depth, or drop `--changed` and check every page.
