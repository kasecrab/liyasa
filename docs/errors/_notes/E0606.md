A `manual` fact source has passed its expiry.

`manual` is the honest escape hatch for a claim that nothing machine-readable
can confirm: someone asserted the value, and said how long it should be trusted.
That period is over.

## Fix it

Re-confirm the value and renew the attestation, or replace the source with one
that can be checked. An expired attestation is meant to be noisy; the
alternative is a value that ages silently, which is the failure this product
exists to prevent.
