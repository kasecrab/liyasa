The site exceeded the total variant cap.

A page that reads a dimension value is built once per combination, so the count
multiplies: three versions, two locales, and three regions is eighteen copies of
every page that reads all three.

## Fix it

Narrow what each page reads rather than raising the cap. Most pages need one
dimension, not all of them, and a page that reads a dimension only inside a
conditional still counts as reading it.

`build.maxVariants` and `build.maxVariantsPerPage` set the limits.
[`W0710`](/errors/W0710) is the per-page version, which marks the page dynamic
rather than failing.
