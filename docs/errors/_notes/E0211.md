A template called `env("NAME")` for a variable that is not allow-listed.

Build environment is not readable by default, because a page that can read any
environment variable is a page that can leak a deployment secret into published
HTML.

## Fix it

List the variables a build may read:

```json
{ "build": { "env": ["ACME_DOCS_TIER"] } }
```

Only list variables whose values are safe to publish. A change to an
allow-listed value invalidates every page that read it, which is
[`W0718`](/errors/W0718).
