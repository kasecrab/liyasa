The directive names a component that is not registered. The message suggests the
closest name it knows.

## Fix it

[The component gallery](/reference/gallery) lists every built-in component with
its props and a working example. Names are lower case with hyphens
(`code-group`), and most components also accept a capitalised alias
(`CodeGroup`) for content imported from another tool.

A component of your own goes in `components/` as a minijinja template with a
prop schema in its front matter. A file there that is not a valid definition is
[`E0356`](/errors/E0356).
