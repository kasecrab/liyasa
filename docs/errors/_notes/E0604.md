A fact source could not be refreshed. The message names the source and what
failed.

## Fix it

- **A `url` source**: the endpoint was unreachable, refused, or returned
  something that is not the shape the source expects. If the network policy
  blocked it, you get [`E0806`](/errors/E0806) instead; allow-list the host.
- **A `repo` source**: the repository, the branch, or the path has moved.
- **A `command` source**: the command failed, or its hash no longer matches
  what the server allowed ([`E0621`](/errors/E0621)).

On an isolated network, `url` sources fail by design rather than silently
serving a stale value. That is the right failure: a fact whose source cannot be
read is not verified.
