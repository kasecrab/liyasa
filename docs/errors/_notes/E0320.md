A value from below the `operator` trust level contained a line break and was
refused rather than interpolated.

An untrusted multi-line value can close the construct it sits in and open a new
one, which turns a value into markup. Liyasa refuses instead of guessing.

## Fix it

Single-line untrusted values are escaped and pass through safely. If the content
is genuinely multi-line and genuinely trusted, it belongs in a snippet or a
fact, both of which are operator-controlled, rather than in an interpolated
value.
