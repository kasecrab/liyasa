A `$ref` in an OpenAPI document could not be resolved.

## Fix it

- **A local ref** (`#/components/schemas/Deployment`) names something that is not
  there. Check for a rename.
- **A file ref** (`./schemas/deployment.yaml#/Deployment`) is resolved relative
  to the document that contains it, not to the project root.
- **A remote ref** must be on a host listed in `network.allowHosts.specRefs`;
  otherwise it is refused as [`E0806`](/errors/E0806) rather than fetched, which
  is what stops a specification from making the build fetch arbitrary URLs.
