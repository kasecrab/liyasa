The model asked for a tool that the caller's trust level does not carry.

## Fix it

Nothing is usually wrong: the check is the point. Every tool declares the lowest trust level that may call it, and a run's level is the minimum of its inputs — a run that read a reader's question or an external ticket is `anonymous` or `external` however trusted the operator prompt was.

The assistant has no write tools at any level, so a write tool appearing in an assistant run is a configuration mistake rather than a permissions one. For an agent run, check the merge policy: `automerge-if-verified` and `direct` are unavailable below `member`.
