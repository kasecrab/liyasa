A page that renders per request exceeded the request-path budget, so the default
variant was served instead.

The reader got a page, not an error. This tells you a personalized page is too
expensive to render while someone waits.

## Fix it

Pages that read a bounded set of values — a version, a locale, a region — are
pre-rendered as variants and cost nothing at request time. Only pages that read
free-form `reader.*` fields are rendered on demand, which is
[`W0715`](/errors/W0715).

If a page does not need per-reader content, remove `personalized: true` and let
it be built once.
