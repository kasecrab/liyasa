A source of truth changed and pages that depend on it now disagree with it. The
report names the fact, the old value, the new value, and every block that reads
it.

This is the product working as intended: it converts "somebody should check the
docs after the release" into a list of exactly which paragraphs.

## What to do

1. **If the page only references the fact**, nothing to do — it already renders
   the new value.
2. **If the prose around it is now wrong**, fix the prose. A limit that fell
   from 600 to 60 may invalidate the sentence that called it generous.
3. **If the change was a mistake upstream**, you have found a product bug. Drift
   detection is a second set of eyes on the change log.
