The plan allows a fixed number of projects and they are all in use.

## Fix it

Delete a project that is no longer needed, or upgrade. Deleting is not
immediate — a deleted project sits through a cooling-off period during which it
can be restored, and it keeps its seat in the count until that period ends:

```
liyasa org project list
liyasa org project delete <slug>
liyasa org plan --set pro
```

Free carries one project. Pro and Enterprise have no project limit.

A preview deployment is not a project and does not count here.

Related: [E0851](E0851.md) for the seat limit, which is counted separately.
