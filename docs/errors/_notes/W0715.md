The page reads free-form `reader.*` fields, so it cannot be built once. It is
rendered per request instead.

Not an error, but it moves the page from a file on a CDN to work on a server,
and it means the page cannot be served by a static host at all.

## Fix it

If the page varies over a bounded set — a version, a locale, a region, a product
— use those dimensions instead. They are pre-rendered as variants, work on any
static host, and cost nothing at request time.

Reserve `reader.*` for genuinely per-reader content such as an account name.
Exceeding the request-path budget is [`E0810`](/errors/E0810).
