A file could not be written into the destination, or the destination already
holds a file the import would write.

This is raised when the plan is applied, not when it is built, so an import that
planned cleanly can still stop here.

## Fix it

Import into an empty directory, or overwrite deliberately:

```rust
plan.apply(&source, root, &Apply { force: true })
```

:::check{title="Nothing was written"}
The plan is staged in full and abandoned if any single path is in the way, so a
refused import never leaves half a converted project behind. If you are reading
this, the destination is exactly as it was.
:::
