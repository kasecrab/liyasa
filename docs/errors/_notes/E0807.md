The rate limiter refused the request. It is returned to the caller as HTTP 429
with a `Retry-After` header.

## Fix it

If legitimate readers are hitting it, the limiter is probably keyed wrongly
rather than set too low. It keys on the client address, so behind a proxy every
request appears to come from the proxy unless the proxy is listed:

```json
{ "server": { "trustedProxies": ["10.0.0.0/8"] } }
```

That defaults to none on purpose. A server that trusts `X-Forwarded-For` from
anyone lets a caller claim any address, which makes the limiter decorative.
