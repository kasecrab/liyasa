An image has no alt text.

This is an error rather than a style warning because an image without alt text
is unusable for a reader using a screen reader, and unreadable in the Markdown
output that agents fetch.

## Fix it

Describe what the image *tells the reader*, not what it depicts:

```markdown
::image{src="/assets/deployments.png" alt="The deployment list, showing three successful builds and one failure"}
```

For a genuinely decorative image, write `alt=""`. That is a deliberate signal
to skip it, not a way of silencing this.
