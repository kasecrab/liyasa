The run reached its token, tool-call, or wall-time cap before it finished answering.

## Fix it

Raise `ai.assistant.maxTokens`, or narrow the question so the plan needs fewer retrieval steps. A run that hits the cap on every question usually means the retrieved chunks are larger than they need to be: the assistant's chunks are 200–800 tokens, and a page that is one long section produces chunks at the top of that range.

The cap is per plan, not per site, so raising it raises the cost of every answer.

Related: [E0901](/errors/E0901) for a provider failure, [E0903](/errors/E0903) for a tool refused by policy.
