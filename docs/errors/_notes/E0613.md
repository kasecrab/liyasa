An entry in `verify.runners.custom` is missing something a runner cannot work
without: an `id`, a language to claim, a command template, or a digest-pinned
image. A block marked `verify=compile` against a custom runner reports the same
code, because a declared runner has one command and compiling without running
would need a second.

## Fix it

Fill in the entry:

```json
{ "verify": { "runners": { "custom": [{
  "id": "elixir",
  "languages": ["elixir", "ex"],
  "image": "docker.io/library/elixir@sha256:<64 hex digits>",
  "command": ["elixir", "{file}"]
}] } } }
```

`{file}` is the staged source; `{lang}` is the block's language. A template
that names neither gets the file as its last argument.

Related: [E0610](E0610.md) is the image pin; [E0602](E0602.md) is a language no
runner claims at all.
