The network policy refused a request Liyasa was about to make on your behalf:
fetching an OpenAPI spec, refreshing a fact source, or checking a link.

Those URLs come from configuration and content, which makes them
attacker-influenced on a shared server. The policy blocks private address
ranges, non-HTTPS schemes, and hosts that are not allow-listed, and it
re-validates after every redirect so that a public URL cannot bounce into a
private one.

## Fix it

The message names which rule refused. Allow the host for the use it is needed
for, rather than globally:

```json
{
  "network": {
    "allowHosts": { "factSources": ["status.acme.com"] }
  }
}
```

See [domains](/help/domains).
