The page has no `description` in its front matter.

The description is the search snippet, the social preview, and the line in
`llms.txt` — often the only thing an agent sees before deciding whether to fetch
the page at all.

## Fix it

```yaml
---
title: Rate limits
description: What the API allows per minute, per plan, and what happens when you exceed it.
---
```

Write it as a sentence that stands alone in a list of unrelated links. "Learn
about rate limits" fails that test.

:::note{title="Quote a description that contains a colon"}
`description: Limits: what applies` is not valid YAML. Wrap it in double quotes.
:::
