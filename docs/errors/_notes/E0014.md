`--config` names something that is not a file.

## Fix it

The flag takes a path to a configuration file, not a directory and not a project
name:

```sh
liyasa build --config ./acme-docs/liyasa.json
```

A relative path resolves from the directory you are in, which is the usual
surprise when a script runs from somewhere else than you expect.

If you only meant to say *which project*, drop `--config` and use `--project`,
or run the command from inside the project: every command looks for
`liyasa.json` in the current directory and each parent, and not finding one is
[`E0001`](/errors/E0001).
