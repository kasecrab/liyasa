A project is served at `<project>.liyasa.site`, so its name has to be a DNS
label: between one and sixty-three characters, lowercase letters, digits and
hyphens, not starting or ending with a hyphen. The name given is not, or it is
one of the names reserved for the platform itself.

## Fix it

Pick a name that is a valid label, and set the display name separately — the
display name has no such restriction:

```
liyasa org project create acme-docs --title "Acme Documentation"
```

Reserved labels are `www`, `api`, `app`, `admin`, `dashboard`, `status`,
`assets`, `cdn`, `mail` and `liyasa`.

A project on a custom domain still has a subdomain, because the custom domain
is an alias for it rather than a replacement.

Related: [E0815](E0815.md) for custom domain paths, and [E0814](E0814.md) when
a domain is already claimed.
