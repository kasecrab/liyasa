The converted navigation names a page the import did not produce.

Usually the entry was already dead before the migration: a page deleted from the
source repository without updating the configuration that lists it. External
links are not checked and never raise this.

## Fix it

Remove the entry, or restore the page.

This is a project-level item rather than a page-level one, so it does not reduce
any page's confidence score. It is a defect in the tree, not in a page.

[`E0104`](/errors/E0104) is what the same situation becomes once the converted
project is built, so fixing it now saves a build failure later.
