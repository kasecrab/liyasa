`llms.txt` does not list every indexable page, so an agent reading the index
cannot discover the whole site.

The usual cause is a custom `llms.txt` that has fallen behind the content it
describes.

## Fix it

Remove `agents.llms.custom` and let the build generate the index from the
navigation tree, or update the custom file. If a page is deliberately absent,
mark it in its own front matter rather than by omission from the index:

```yaml
---
title: Internal runbook
ai: false
---
```

`.liyasa-aiignore` does the same for a set of files. See
[writing for agents](/guides/writing-for-agents).
