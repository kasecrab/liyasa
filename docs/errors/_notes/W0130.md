The page is routable but no navigation node names it, so a reader can only reach
it from a link or a search result.

Usually that is a mistake: a page added without being placed.

## Fix it

Add it to `navigation`, or say that the omission is deliberate in the page's own
front matter:

```yaml
---
title: Legacy migration notes
hidden: true
---
```

`hidden: true` also removes it from the sitemap, search, and `llms.txt`; turn
those back on individually with `search: true`, `ai: true`, or `noindex: false`.

Setting `"autofill": true` on the navigation tree places unplaced pages
automatically, which suits a site under rapid change and not one whose order
carries meaning.
