A value in `security.csp` or `network.allowHosts.embeds` is not a valid content
security policy source expression.

## Fix it

A source is a host (`images.acme.com`), a host with a scheme
(`https://images.acme.com`), a scheme (`https:`), a wildcard host
(`*.acme.com`), or one of the quoted keywords such as `'self'`. A bare URL with
a path is not a source expression, and neither is a comma-separated list in one
string.

```json
{ "security": { "csp": { "extraImgSrc": ["images.acme.com", "https://cdn.acme.com"] } } }
```

The policy is otherwise derived from what the site actually loads, so most sites
need none of this. A new host appearing in content and being added automatically
is [`W0719`](/errors/W0719).
