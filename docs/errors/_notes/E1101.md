The importer looked for a configuration file at the path it was given and found
none, so the directory is not a project it recognises.

The Mintlify importer looks for `docs.json` and then `mint.json`. The Docusaurus
importer looks for `docusaurus.config` with a `.json`, `.js`, `.mjs`, `.cjs`, or
`.ts` extension.

## Fix it

Point at the directory that holds the configuration file, not at the repository
that holds the directory. Documentation usually lives in a subdirectory:

```
acme/                      the repository
└── docs/                  point here
    └── docs.json
```

A monorepo with several documentation sites is imported one site at a time.

Nothing is planned and nothing is written when this fires.
