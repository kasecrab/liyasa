A verified code sample ran and produced something other than what the page
claims. The diagnostic carries the difference.

This is the check working. Before changing the expectation, establish which of
the two is wrong: the page, or the product.

## Fix it

A sample is verified by marking its fence:

````markdown
```python {verify="python" expect="600"}
from acme import Client
print(Client().limits().requests_per_minute)
```
````

If the sample needs setup the reader does not see, put it in the runner rather
than in the page. A sample that only passes because of hidden state is a sample
that does not work when copied.
