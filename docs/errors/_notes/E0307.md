The page's Markdown is above 100,000 characters.

At that size the page is slow for a reader, and it exceeds the fetch buffers
agents document, so it is truncated silently — which is worse than a failure.

## Fix it

Split it at a boundary a reader would recognise. A page this long usually has
several, and its table of contents will show you where.

If it is genuinely one generated table, put the data in a downloadable file and
keep a summary on the page. [`W0308`](/errors/W0308) is the warning band at
50,000 characters, and [`W0321`](/errors/W0321) fires when machine-generated
bulk elements dominate an oversized page.
