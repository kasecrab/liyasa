A directory the build reserves for something other than content holds files with
a page extension, and those files are not served anywhere: no route, no entry in
the navigation or the sitemap, nothing in `dist/`.

## Fix it

Move the file under a content directory:

```sh
git mv snippets/pricing.md guides/pricing.md
```

The reserved names are `snippets/`, `assets/`, `components/`, `facts/` and
`theme/`, and any path segment starting with `_`. Each holds something the build
consumes rather than serves — a snippet is pulled into a page by
`{% snippet "pricing" %}`, an asset is copied to `dist/` as a file — so a `.md`
sitting there is content the site never shows.

If the file is meant to be included rather than served, nothing is wrong and the
warning is the confirmation: leave it where it is.

Related: [`E0403`](E0403) for an asset a page names and the build does not have,
and [`W0130`](W0130) for a page that is served but no navigation reaches.
