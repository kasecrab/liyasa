The feature needs the companion runtime and it is not installed.

The companion is a pinned headless browser, fetched into the user cache
directory. Maths with KaTeX, Mermaid pre-rendering, PDF export, accessibility
tests in a real browser, Lighthouse budgets, and screenshot verification all use
it.

## Fix it

```sh
liyasa companion install
```

Nothing in that list is required to build a site. Without the companion, maths
renders through the pure-Rust path, Mermaid renders in the browser from the
fence source, and the rest explain why they cannot run rather than failing the
build. See [sandbox setup](/help/sandbox).
