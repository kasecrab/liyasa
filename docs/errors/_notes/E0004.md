The operation needs a sandbox and no container runtime was found.

Executing code samples means executing code from a repository, so it happens in
a container with no network by default.

## Fix it

Install Docker or Podman and check the daemon is reachable by your user:

```sh
podman info
docker info
```

"Cannot connect to the Docker daemon" is a daemon that is not running, or a
socket your user cannot reach; on Linux that is usually group membership, and it
takes a new login session to take effect. See
[sandbox setup](/help/sandbox).
