`liyasa search` found a built site with no search index in it, or an index it
could not read.

## Fix it

```sh
liyasa build
liyasa search "rate limits"
```

Or point at an index directly:

```sh
liyasa search "rate limits" --index dist/_liyasa/search
```

An index that exists but will not open is a different matter: it is either
truncated ([`E1003`](/errors/E1003)) or written by a newer format version than
this reader understands ([`E1002`](/errors/E1002)). A clean rebuild fixes the
first and an upgrade fixes the second.
