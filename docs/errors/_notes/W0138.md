`auth.mode` is `managed`, which signs people in by emailing them a link, and
there is no `mail` block saying where to send it. Every sign-in request will be
accepted and no link will arrive.

## Fix it

Add a sender and a server:

```json
{ "mail": { "from": "Docs <docs@example.com>",
            "smtp": { "host": "smtp.example.com", "port": 587,
                      "username": "docs", "password": "env:SMTP_PASSWORD" } } }
```

`mail.smtp.password` holds a reference and never the password itself:
`secret:<name>` reads it from the secret store, `env:<VAR>` from the
environment. `liyasa.json` is committed to the repository the docs live in.

If you did not mean to sign people in by email, set `auth.mode` to the way this
instance actually identifies readers.

See [W0137](/errors/W0137) for an operator whose subject no sign-in issues.
