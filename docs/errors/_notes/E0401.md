A link points at a route that does not exist.

## Fix it

Internal links are written as routes beginning with `/`, and a route comes from
where the file sits: `guides/install.md` is `/guides/install`. Relative links to
source files resolve too, and are converted to routes at build time.

If the target moved, add a [redirect](/guides/linking) in the same commit that
moved it.

`build.strictLinks` decides whether this fails the build or warns. On a site
that is verified at all, it should fail.
