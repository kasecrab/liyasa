The release index could not be read, or it lists nothing for this platform.

## Fix it

- **Unreachable or unparseable**: usually a network that intercepts HTTPS, or an
  offline machine. Install from the releases page instead.
- **Nothing for this target**: the message names the version and the platform
  triple. Liyasa publishes Linux (x86-64 and aarch64, glibc and musl), macOS
  (Apple silicon and Intel), and Windows (x86-64). A platform outside that set
  builds from source:

```sh
cargo install liyasa
```

On an air-gapped machine, self-updating is not the mechanism to use at all.
Mirror the release artifacts and install them the way you install everything
else.
