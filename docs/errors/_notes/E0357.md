An `embed` names a provider that is not in the allow list.

Embedding is loading a third party's script into your documentation, so the set
of providers is explicit rather than open.

## Fix it

```json
{ "network": { "allowHosts": { "embeds": ["player.vimeo.com", "www.youtube.com"] } } }
```

Adding a provider also adds it to the content security policy, which is the
point: the policy and the allow list are the same decision written once.
