A `:::` closes a container directive that was never opened.

## Fix it

Usually the other end of [`E0310`](/errors/E0310): an opening fence that failed
to parse, leaving its closing fence orphaned. Check the opening line for a prop
syntax error, which is [`E0312`](/errors/E0312).

Also check nesting. A container inside another needs more colons on the outer
one, or the first `:::` closes both:

```markdown
::::steps

:::step{title="One"}
Body.
:::

::::
```
