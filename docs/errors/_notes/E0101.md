`liyasa.json` did not parse as JSON. The message carries the line and column of
the first thing that did not fit.

JSON allows no trailing commas, no comments, no single quotes, and no unquoted
keys. Every one of those is legal in the formats people arrive from.

## Fix it

Point `$schema` at the published schema so your editor reports this as you
type rather than at build time:

```json
{ "$schema": "https://kasecrab.github.io/liyasa/schema/v1/liyasa.schema.json" }
```
