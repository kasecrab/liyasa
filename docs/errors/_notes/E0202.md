A template statement is not well formed: an unclosed `{% if %}`, a `{% endfor %}`
with no `{% for %}`, or a typo in a tag name.

## Fix it

The diagnostic points at the line and column. Two causes are easy to miss:

- **`{% extends %}` in a page** is [`E0202`](/errors/E0202) by design. Pages do
  not extend templates; layout belongs to the theme.
- **A block statement that does not nest with the Markdown structure** — an
  `{% if %}` opened inside a list item and closed outside it — is
  [`E0210`](/errors/E0210) instead.
