A file in the source project could not be read, or was read and is not UTF-8.
The message says which, and names the file.

Only files the importer opens as text can raise it: `.md`, `.mdx`, `.json`,
`.yaml`, and `.yml`. Images, fonts, and archives are copied byte for byte and
never decoded.

## Fix it

For the encoding case, which is the common one, re-save the named file as UTF-8.
It is usually a page written years ago in an editor that defaulted to UTF-16 or
Latin-1.

:::warning{title="The import does not stop here"}
That one file is skipped and every other page still converts, so a migration
that reported this is incomplete in a way the finished project will not show
you. Read the migration report before assuming everything came across.
:::
