`build.basePath`, or the base path attached to a custom domain, is not a path a
site can be served under. One instance serves several hosts at different
subpaths, so the base path has to be unambiguous before any of them answers.

## Fix it

Write it with a leading slash and no trailing slash:

```json
{ "build": { "basePath": "/docs" } }
```

Serving at the root is the empty string, not `"/"`. A relative segment (`..`),
an empty segment (`//`), a query or a fragment are all rejected: they make the
prefix a request has to match ambiguous.

Related: [E0801](E0801.md) for the domain itself failing to verify.
