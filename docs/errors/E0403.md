# E0403

**Missing image or asset**

| | |
|---|---|
| Severity | Error |
| Area | Navigation and links |
| Raised by | `liyasa-build` |

This diagnostic comes from `liyasa-build`. The message carries the file, the line, and the value that caused it; run the command again with `--json` to get it as structured output.
