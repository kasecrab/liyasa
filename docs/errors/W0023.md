# W0023

**`--changed` could not narrow every problem; some carry no location**

| | |
|---|---|
| Severity | Warning |
| Area | CLI and I/O |
| Raised by | `liyasa-cli` |

`liyasa verify --changed <ref>` narrows the report to the pages that differ
from the reference. Some problems cannot be placed on a page — the build
reports a broken internal link ([`E0401`](/errors/E0401)), a broken anchor
([`E0402`](/errors/E0402)) and a missing asset ([`E0403`](/errors/E0403))
without a source location — so they are all shown, whichever page they are on.

They are shown rather than dropped on purpose: a problem on the page you *did*
change is unplaceable too, and hiding it would be the worse mistake.

## Fix it

Nothing is broken. Read the message, which names the route:

```
`/nope` on `/guides/install` is not a route
```

The count in this warning is how many problems `--changed` could not narrow.
It goes away when the build gives a link diagnostic a span.
