# E0501

**OpenAPI document invalid (JSON pointer)**

| | |
|---|---|
| Severity | Error |
| Area | OpenAPI and API docs |
| Raised by | `liyasa-openapi` |

This diagnostic comes from `liyasa-openapi`. The message carries the file, the line, and the value that caused it; run the command again with `--json` to get it as structured output.
