# E0853

**This feature is not included in the organization's plan**

| | |
|---|---|
| Severity | Error |
| Area | Server, auth, deployments, network |
| Raised by | `liyasa-server` |

The operation needs something the organization's plan does not include — a
custom domain, a preview deployment, SSO, SCIM, audit streaming or static
egress — so it was refused before anything was changed.

## Fix it

Check what the plan carries and move to one that includes it:

```
liyasa org plan
liyasa org plan --set enterprise
```

Custom domains and previews are on Pro and above. SSO, SCIM, audit streaming,
static egress, SLAs and invoicing are Enterprise.

An OSS instance you run yourself has every feature and no quota: this code
cannot be raised there, because the plan is `unlimited` by default and nothing
configures it otherwise.

Related: [E0850](E0850.md) when the feature is included and its quota is spent,
which is a different refusal with a different fix.
