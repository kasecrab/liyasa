# E0807

**Rate limit exceeded (returned as 429)**

| | |
|---|---|
| Severity | Error |
| Area | Server, auth, deployments, network |
| Raised by | `liyasa-server` |

This diagnostic comes from `liyasa-server`. The message carries the file, the line, and the value that caused it; run the command again with `--json` to get it as structured output.

## Getting help

[Domains, certificates, and deployments](/help/domains) covers the codes in this range, what usually causes them, and what to try first.

Every code is listed in [the error reference](/errors).
