# E0021

**A network request failed (policy, DNS, TLS, timeout, or the host)**

| | |
|---|---|
| Severity | Error |
| Area | CLI and I/O |
| Raised by | `liyasa-cli` |

A command that needed the network did not get an answer, and the message says
which of the five reasons it was: the request was refused by policy, the name
did not resolve, the certificate did not verify, the request timed out, or the
host answered with a status the command could not use.

Only `doctor`, `broken-links`, `validate` with a remote specification, and
`update` reach the network at all. A build never does.

## Fix it

Find out which reason applies, then:

```sh
liyasa doctor           # what this machine can reach
liyasa build --offline  # or skip the network entirely
```

A request refused by policy is not a network fault: `network.allowHosts` lists
the hosts each kind of fetch may reach, and a host on a private address needs
`network.allowPrivate` as well. A link that answers a status is
[`W0404`](/errors/W0404), not this. See
[`W0018`](/errors/W0018) for a run that skipped external links altogether.
