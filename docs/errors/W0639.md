# W0639

**A page's `reviewed:` date is not a date Liyasa can read**

| | |
|---|---|
| Severity | Warning |
| Area | Verification and facts |
| Raised by | `liyasa-verify` |

The page's `reviewed:` front matter holds something Liyasa could not read as a
date, so the editorial review cadence has nothing to measure against and the
page is flagged as needing review whatever the value said.

## Fix it

Write the date as `YYYY-MM-DD`:

```yaml
---
title: Rate limits
reviewed: 2026-09-28
---
```

A full timestamp works too — `2026-09-28T13:45:00Z` — and only its date part is
read, because a review cadence is measured in whole days.

:::note{title="Quote a date YAML would read as something else"}
An unquoted `reviewed: 2026-9-8` is not a date to Liyasa: the month and day need
two digits. Prefer `2026-09-08`.
:::

A page with no `reviewed:` at all is not this warning. It is flagged as needing
review, because a page nobody has reviewed is what a cadence exists to surface,
and nothing was misread.

Set the cadence itself with `content.reviewCadence`, which defaults to 180 days.
