# E0855

**Data may not leave the region the project was created in**

| | |
|---|---|
| Severity | Error |
| Area | Server, auth, deployments, network |
| Raised by | `liyasa-server` |

A request reached a server in one region carrying analytics or assistant data
for a project that lives in another. Writing it would put the data outside the
region the project was created in, which is the one thing the region setting
promises.

## Fix it

Send the request to the project's own region. The regional hostnames are:

```
us.liyasa.site    eu.liyasa.site    apac.liyasa.site
```

If traffic is arriving in the wrong region because of a CDN or a load balancer
in front of Liyasa, route on the project rather than on the reader: a reader in
Frankfurt using a project created in the United States is served from the
United States, deliberately.

A project that genuinely needs to collect data in a second region needs a
second project there.

Related: [E0854](E0854.md) on why the project cannot simply be moved.
