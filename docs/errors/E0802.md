# E0802

**Certificate issuance failed**

| | |
|---|---|
| Severity | Error |
| Area | Server, auth, deployments, network |
| Raised by | `liyasa-server` |

This diagnostic comes from `liyasa-server`. The message carries the file, the line, and the value that caused it; run the command again with `--json` to get it as structured output.
