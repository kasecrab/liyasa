# E0804

**Deployment failed**

| | |
|---|---|
| Severity | Error |
| Area | Server, auth, deployments, network |
| Raised by | `liyasa-server` |

A deployment could not be completed: the build could not be queued, or the
pointer switch that makes a build live did not go through.

## Fix it

This is a server-side failure rather than something wrong with your content,
so the first place to look is the server log next to the request. The detail
field names which half failed.

If the edge purge failed and the pointer moved, the response says so and the
status is 502: the new build is live at the origin and the CDN is serving
stale bytes until its own TTL expires. Purging that environment's surrogate
key by hand fixes it; the tag is `liyasa-<project>-<environment>`.

See [`E0805`](/errors/E0805) when the build you asked to roll back to is no
longer retained, and [`E0809`](/errors/E0809) when the build queue is full.
