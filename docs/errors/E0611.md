# E0611

**`remote` sandbox has no runner service configured**

| | |
|---|---|
| Severity | Error |
| Area | Verification and facts |
| Raised by | `liyasa-verify` |

`verify.runners.sandbox` is `remote`, so code blocks are meant to run on a
Liyasa runner service, and nothing told Liyasa where that service is.

## Fix it

Point verification at the service, or run the containers locally instead:

```json
{ "verify": { "runners": { "sandbox": "container" } } }
```

In-process checks — links, facts, schemas, HTTP mocks, Mermaid — need no
sandbox and keep running whatever this key says, so a site with no code samples
is unaffected by it.

Related: [E0004](E0004.md) is `container` with no Docker or Podman installed;
[E0610](E0610.md) is an image with no digest; [E0620](E0620.md) is the server
refusing `local`.
