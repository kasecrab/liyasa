# W0911

**Re-index cost needs confirmation (above the auto-approval threshold, or unpriced)**

| | |
|---|---|
| Severity | Warning |
| Area | AI, agent, automations |
| Raised by | `liyasa-ai` |

A full re-index was requested and its estimated cost is above `ai.reindex.autoApproveCents`, or no list price is known for the embedding model so there is no estimate to compare.

## Fix it

Confirm the run on the dashboard, or with `liyasa assistant reindex --yes`. The old index keeps answering every query until the new one is complete, so confirming late costs nothing but time.

To let runs of this size start on their own, raise the threshold:

```json
{ "ai": { "reindex": { "autoApproveCents": 2000 } } }
```

An unpriced model is never auto-approved, whatever the threshold. That is deliberate: treating an unknown price as zero would auto-approve exactly the runs nobody has costed.

The figure is an estimate. Token counts are vendor-neutral rather than taken from the provider's own tokenizer, so expect it to differ from an invoice by some tens of percent.

Related: [W0906](/errors/W0906), raised when a model or dimension change is what scheduled the re-index.
