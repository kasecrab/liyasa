# E0612

**The sandbox could not run the check**

| | |
|---|---|
| Severity | Error |
| Area | Verification and facts |
| Raised by | `liyasa-verify` |

The sandbox was available and the job never ran: the container engine refused
to start it, the image could not be pulled, or the job's files could not be
written. The block itself has not been judged — this is not a failing sample.

## Fix it

Read the detail on the diagnostic; it is the engine's own words. The three that
come up:

- **pull failed** — the pinned digest is not in the registry this machine can
  reach. Set `verify.runners.registry` for an offline mirror, or re-run
  `liyasa lock` against a registry that has it.
- **permission denied** — the invoking user cannot talk to the container
  daemon. Podman needs no daemon; Docker needs the user in its group.
- **no space left** — the image and its layers do not fit. `docker image prune`
  or `podman image prune`.

Related: [E0004](E0004.md) is no engine at all; [E0610](E0610.md) is an image
with no digest; [E0603](E0603.md) is a job that started and ran too long.
