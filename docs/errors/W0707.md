# W0707

**Build clock fell back to the wall clock; build is not reproducible**

| | |
|---|---|
| Severity | Warning |
| Area | Build, cache, assets, determinism |
| Raised by | `liyasa-build` |

No build clock was supplied, so the build used the wall clock. Two builds of the
same commit will differ, which defeats the artifact cache and
`--check-determinism`.

## Fix it

Pass the commit timestamp in CI:

```sh
liyasa build --build-time "$(git log -1 --format=%ct)"
```

Locally it does not matter, which is why this is a warning.
