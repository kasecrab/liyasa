# W0707

**Build clock fell back to the wall clock; build is not reproducible**

| | |
|---|---|
| Severity | Warning |
| Area | Build, cache, assets, determinism |
| Raised by | `liyasa-build` |

No build clock was supplied, so the build used the wall clock. Two builds of the
same commit will differ, which defeats the artifact cache and
`--check-determinism`.

## Fix it

Give the build a timestamp that comes from the source rather than from the
clock. In CI:

```sh
SOURCE_DATE_EPOCH="$(git log -1 --format=%ct)" liyasa build
```

Building inside a git repository is enough on its own: the commit time of `HEAD`
is the third source, and a checkout that has one never reaches this warning.

A command-line spelling for the same value is specified (§6.6.2 rule 1) and is
not built yet, so the environment variable is the way to set it by hand today.

Locally it does not matter, which is why this is a warning.
