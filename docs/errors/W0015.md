# W0015

**Companion runtime version differs from the one `liyasa.lock` records**

| | |
|---|---|
| Severity | Warning |
| Area | CLI and I/O |
| Raised by | `liyasa-cli` |

The installed companion runtime is not the version `liyasa.lock` records.

The companion renders maths, pre-renders diagrams to SVG, exports PDF, and takes
screenshots. Those outputs are part of the built site, so a different companion
can produce a different site from the same sources — which is exactly what the
lock exists to prevent.

## Fix it

Reinstall the companion the lock names:

```sh
liyasa companion install
```

Or, if the newer companion is the one you mean to use, record it:

```sh
liyasa lock update
```

Either is fine. What is not fine is leaving them disagreeing, because then
`liyasa.lock` describes a build nobody is producing.
