# E0205

**Include or snippet not found**

| | |
|---|---|
| Severity | Error |
| Area | Templating and Source Document |
| Raised by | `liyasa-markdown` |

An `{% include %}` or `{% snippet %}` names a file the build did not find.

## Fix it

`{% snippet "auth-note" %}` resolves to `snippets/auth-note.md` by file stem.
`{% include "snippets/auth-note.md" %}` takes the full path from the project
root. Check the file is under `snippets/` and that the stem matches.

[`E0206`](/errors/E0206) is the related failure: two snippets that include each
other.
