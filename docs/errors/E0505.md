# E0505

**Duplicate operation ID**

| | |
|---|---|
| Severity | Error |
| Area | OpenAPI and API docs |
| Raised by | `liyasa-openapi` |

:::info{title="This page is not written yet"}
`E0505` is registered and raised by `liyasa-openapi`, and everything above is generated from the registry. What causes it and how to fix it has not been written yet.

The message itself carries the file, the line, and the value that caused it; `--json` gives you the same as structured output.
:::
