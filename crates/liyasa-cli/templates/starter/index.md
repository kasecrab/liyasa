## Why this is not a wiki

A wiki goes stale quietly. Liyasa builds the claims into the page and checks
them: a code block that no longer compiles, a price that no longer matches
billing, a link that no longer resolves are all build failures rather than
things a reader discovers for you.

Start with the [quickstart](/guides/quickstart).
